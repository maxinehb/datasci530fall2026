OpenAlex

OpenAlex is a free database of research publications where one can get information such as a work’s title, publication year, citation count, authors, and their affiliated institutions. We will be using its API to search for works by title and compare the results. An API lets my Python code request information from a website.

Summary of Findings

Overall, the results show that research using artificial intelligence syntax has grown exponentially and the authors writing these publications are affiliated with institutions globally. The title terms "artificial intelligence," "AI," "LLM," and "GPT" showed different rates of growth over time, highlighting how the choice of search term affects the results drastically. Research mentioning AI also spans several fields and has slightly change over the years. Computer science remained the most prominent field when comparing fields talking about AI in 2022 and 2026, while social sciences rose in ranking, suggesting an increasing importance on AI in 2026.

# build one table and count institutions for the bar chart
work_rows = []
institution_counts = {}

for work_number, work in enumerate(top10_works_ai_2000, start=1):
    author_names = []
    work_institutions = []

    for authorship in work["authorships"]:
        full_name = authorship["author"]["display_name"]
        name_parts = full_name.split()

        # abbreviate the first name
        if len(name_parts) > 1:
            short_name = name_parts[0][0] + ". " + " ".join(name_parts[1:])
        else:
            short_name = full_name

        author_names.append(short_name)

        for institution in authorship["institutions"]:
            institution_name = institution["display_name"]

            # Show an institution only once in this work's table row
            if institution_name not in work_institutions:
                work_institutions.append(institution_name)

            # Count this author's affiliation for the bar chart
            if institution_name not in institution_counts:
                institution_counts[institution_name] = 0

        "Work": work_number,
        "Title": work["title"],
        "Citations": work["cited_by_count"],

To answer this question, I used the OpenAlex Works API to search for works with “AI” in their titles. I converted the field counts into DataFrames and merged them by field. # question 5: How has the discussion of AI changed from 2022 to 2026?
years_q5 = [2022, 2026]
field_tables = {}

for year in years_q5:
    if year == 2022:
        end_date = "2022-12-31"
    else:
        end_date = "2026-09-27"

    url_q5 = (
        'https://api.openalex.org/works?filter=title.search:"AI",'
        f'from_publication_date:{year}-01-01,'
        f'to_publication_date:{end_date}'
        '&group_by=primary_topic.field.id'
        '&per_page=200'
    )

    search_results_q5 = requests.get(url_q5).json()

    table_field = pd.DataFrame(search_results_q5["group_by"])
    table_field = table_field[["key_display_name", "count"]].rename(
        columns={
            "key_display_name": "Field",
            "count": f"Works {year}"
        }
    )

    field_tables[year] = table_field

# merge on 'field'
table_q5 = field_tables[2022].merge(
    field_tables[2026],
    on="Field",
    how="outer"
)

table_q5 = table_q5.fillna(0)

for year in years_q5:
