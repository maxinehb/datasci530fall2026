OpenAlex

OpenAlex is a free database of research publications where one can get information such as a work’s title, publication year, citation count, authors, and their affiliated institutions. Research mentioning AI also spans several fields and has slightly change over the years. Computer science remained the most prominent field when comparing fields talking about AI in 2022 and 2026, while social sciences rose in ranking, suggesting an increasing importance on AI in 2026.

Due to the large amount of information outputed, I saved this table as a separate figure file, and instead am presenting the simplified table, where the institutions are not directly linked to each author. In the table, I abbreviate the authors' first names and author lists longer than eight names are abbreviated with “et al,” and limit institutions to three per work. # top ten works, authors, institutions, and affiliation frequencies
url_openalex_ai_2000_cited = (
    url_openalex_ai_2000 + '&sort=cited_by_count:desc'
)
search_results_ai_2000_cited = requests.get(
    url_openalex_ai_2000_cited
).json()
top10_works_ai_2000 = search_results_ai_2000_cited["results"][:10]

work_rows = []
institution_counts = {}

for work_number, work in enumerate(top10_works_ai_2000, start=1):
    author_names = []
    work_institutions = []
    missing_affiliation = False

    for authorship in work["authorships"]:
        full_name = authorship["author"]["display_name"]

        # abbreviate names
        if "," in full_name:
            surname, given_name = full_name.split(",", 1)
            given_name = given_name.strip()
            short_name = surname.strip()
            if given_name:
                short_name = given_name[0] + ". " + short_name
        else:
            name_parts = full_name.split()
            short_name = full_name
            if len(name_parts) > 1:
                short_name = name_parts[0][0] + ". " + " ".join(name_parts[1:])

        author_names.append(short_name)

        if not authorship["institutions"]:
            missing_affiliation = True

        # count each institution once per author
        author_institutions = []

        for institution in authorship["institutions"]:
            name = institution["display_name"]

            if name not in work_institutions:
                work_institutions.append(name)

            if name not in author_institutions:
                author_institutions.append(name)
                if name not in institution_counts:
                    institution_counts[name] = 0
                institution_counts[name] += 1

    # shorten only the author and institution columns
    author_text = "; ".join(author_names[:8])
    if len(author_names) > 5:
        author_text += "; et al."

    institution_text = "; ".join(work_institutions[:3])
    if len(work_institutions) > 3:
        institution_text += "; additional institutions"

    if not work_institutions:
        institution_text = "Not listed for any author"
    elif missing_affiliation:
        institution_text += "; not listed for some authors"

    work_rows.append({
        "Work": work_number,
        "Title": work["title"],
        "Citations": work["cited_by_count"],
        "Authors": author_text,
        "Affiliated institutions": institution_text
    })

table_ai_2000_concise = pd.DataFrame(work_rows)

terms = ["artificial intelligence", "LLM", "GPT", "AI"]

Which research fields dominate the discussion of AI in 2022 and 2026?

I compare the rankings of research fields among works with “AI” in their titles, using all publications from 2022 and publications from January 1, 2026 through September 27, 2026. I chose this question to investigate whether the research fields most prominently discussing AI changed between these two periods.

To answer this question, I used the OpenAlex Works API to search for works with “AI” in their titles. I filtered the results separately for each period and grouped them by the research field associated with each work’s primary topic. I converted the field counts into DataFrames and merged them by field. I ranked the fields within each year by their number of matching works and created a bump chart displaying fields in the top five of either year. Note that the comparison uses a full year for 2022 and a partial year for 2026 (up to Semptember 27th).

# question 5: How has the discussion of AI changed from 2022 to 2026?
years_q5 = [2022, 2026]
field_tables = {}

for year in years_q5:
    if year == 2022:
        end_date = "2022-12-31"
    else:
        end_date = "2026-09-27"

    url_q5 = (
        'https://api.openalex.org/works?filter=title.search:"AI",'
        f'from_publication_date:{year}-01-01,'
        f'to_publication_date:{end_date}'
        '&group_by=primary_topic.field.id'
        '&per_page=200'
    )

    search_results_q5 = requests.get(url_q5).json()

    table_field = pd.DataFrame(search_results_q5["group_by"])
    table_field = table_field[["key_display_name", "count"]].rename(
        columns={
            "key_display_name": "Field",
            "count": f"Works {year}"
        }
    )

    field_tables[year] = table_field

# merge on 'field'
table_q5 = field_tables[2022].merge(
    field_tables[2026],
    on="Field",
    how="outer"
)

table_q5 = table_q5.fillna(0)

for year in years_q5:
    table_q5[f"Works {year}"] = table_q5[f"Works {year}"].astype(int)

    # highest count gets rank 1; equal counts receive equal ranks
    table_q5[f"Rank {year}"] = table_q5[f"Works {year}"].rank(
        ascending=False, method="min"
    ).astype(int)

# show top 5 ranked each year
chart_q5 = table_q5[
    (table_q5["Rank 2022"] <= 5) |
    (table_q5["Rank 2026"] <= 5)
].copy()

chart_q5 = chart_q5.sort_values("Rank 2022").reset_index(drop=True)


chart_q5["Rank improvement"] = (
    chart_q5["Rank 2022"] - chart_q5["Rank 2026"]
)
